## 🚀 Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

### 2) Install dependencies

```bash
npm install
```

### 3) Configure environment

```bash
cp .env.example .env
```

### 4) Run the app

```bash
npm run dev
```

Open your browser and visit `http://localhost:3000`.
